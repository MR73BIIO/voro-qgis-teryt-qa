# voro-qgis-teryt-qa

QGIS plugin for quality checks of Polish administrative boundaries (PRG) against the official TERC register.

The checks come from [voro-gis-qa](https://github.com/MR73BIIO/voro-gis-qa), where they were built and measured in Python. This repository moves them into QGIS as a Processing algorithm.

## Status

Stage 0: repository and sealed prediction. No plugin code yet.

The prediction for version 0.1 is written down in `PREDICTION.md` before any code. Results will be compared against it, not adjusted to it.
